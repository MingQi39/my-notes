# 009 · AI 知识库

由 OpenCode（DeepSeek V4 Pro）驱动的个人智能知识库，与个人学习笔记（`002.AI` 等）分离存放。

## 目录结构

| 路径 | 用途 |
|------|------|
| [[009.AI知识库/wiki/使用指南\|使用指南]] | 上手说明 |
| `raw/` | 原始素材（AI 只读） |
| `wiki/` | AI 维护的消化笔记 |
| `assets/` | 配图资源 |
| `AI_CONFIG.md` | 自定义触发词、知识域等 |

## 快速开始

在 Obsidian 侧边栏 OpenCode 面板中试试：

```
帮我创建一篇笔记，标题是《我的第一篇 AI 笔记》
```

或：

```
把这个加到 wiki：[粘贴内容]
```
